# Swipeguide (L2L)

> SwipeGuide was a frontline digital work-instruction platform for manufacturing, now acquired by L2L (formerly Leading2Lean); swipeguide.com redirects to l2l.com. L2L runs a Connected Manufacturing Operations platform (the L2L Dispatch Smart Manufacturing Platform) and exposes the L2L Dispatch REST API (v1.0) for reading and writing shop-floor data — sites, areas, lines, machines, dispatches, pitches, work orders, kaizen and more. API-key auth (query `auth`, `L2LAUTH` header, or POST body) with optional HMAC-SHA512 request signing; JSON default, XML optional; limit/offset pagination (max 2000); custom success/error envelope (HTTP 200 on validation failures).
